# Guess 2023：把 Facebook／Instagram 動態改回時間序，政治態度會變嗎？

**一句話**：2020 年美國大選期間，研究團隊隨機把約 2 萬多名 Facebook 和 Instagram 使用者的動態改成「**最新的排最前面**」（時間序），持續 3 個月（p.3）。結果：使用時間和互動**大幅下降**，看到的內容也明顯改變，但**政治極化、政治知識等態度沒有可偵測的變化**。

> 頁碼說明：引用 **PDF 頁碼**。PDF p.1–7 = 期刊 pp.398–404；p.8 是 2024-12 勘誤，p.9–10 是 2026-03 勘誤，p.11 是引用資訊頁。

## 背景：它想解決什麼問題

- 大眾普遍認為演算法會造成過濾泡泡、極化、假訊息擴散，但演算法不透明，存在很多「**民間理論（folk theories）**」（p.1）。
- 平台內部的 A/B 測試通常只測單一元素，很難評估「整個排序演算法」的總效果（p.1）。
- 時間序動態是政策辯論中常被提出的替代方案（p.1）。

## 研究設計（p.3）

- **合作模式**：Meta 與 Meta 以外的學者合作。
  - 研究費用（受試者酬勞、招募、資料蒐集）由 **Meta 支付**；學者沒有拿 Meta 的報酬（p.6）。
  - **Meta 沒有發表前審查權**，學術主筆擁有最終控制權（p.6）。
- **受試者**：在美國、18 歲以上、同意參加的使用者，從動態頂端的問卷邀請招募。他們比一般使用者更活躍（p.3）。
- **樣本**：Facebook n = 23,391、Instagram n = 21,373（p.3）。
- **介入方式**：2020-09-24 到 12-23，實驗組改成時間序動態，對照組維持原本的演算法（p.3）。
  - 影響範圍包括朋友、粉專、社團的貼文，**不包括廣告**。
  - 估計約有 80% 的內容受到影響（p.3）。
- 研究設計、測量方式和分析計畫都**事先註冊**（p.3）。

## 主要結果

### 1. 使用行為大幅改變（p.3, Figure 1）

- **時間**：
  - Facebook：演算法組的使用時間比一般美國使用者多 73%，時間序組只多 37%（p.3）。
  - Instagram：107% 對比 84%（p.3）。
- **轉去用別的平台**：時間序組的 Instagram 使用者，花在 TikTok 的時間增加 36%、YouTube 增加 20%（p.3）。
- **互動**：Facebook 按讚率從 6.7% 降到 3.1%（p.3）。
- **來自朋友的內容**：Facebook 上減少 24 個百分點（p.3）。

### 2. 看到的內容改變（p.4, Figure 2）

時間序動態相對演算法動態的變化（Facebook；表中數值皆出自 p.4 正文與 Figure 2）：

| 內容 | 演算法 → 時間序 |
|---|---|
| 政治內容 | +15.2% |
| **不可信來源** | **2.6% → 4.4%（+68.8%）** |
| **不文明內容** | **3.2% → 1.8%（−43%）** |
| 含歧視字眼 | 0.03% → 0.019% |
| 立場相同的來源 | 53.7% → 48.1% |
| 立場相反的來源 | 20.7% → 18.7% |
| 溫和或立場混合的來源 | 22.6% → 30.9% |

- 作者認為，「立場相同的內容減少」和「中間內容增加」的幅度，都比「立場相反的內容減少」更大，這「**可以說符合**」演算法造成同溫層或過濾泡泡效應的說法（p.4）。
- Instagram 的不可信來源也增加（1.3% → 1.6%），不文明內容沒有變化（p.4）。

### 3. 態度和行為沒有可偵測的變化（p.4–5, Figure 3）

- **議題極化、情感極化**：沒有顯著差異（p ≈ 1）（p.4）。
- **選舉知識、新聞知識**：沒有差異（p > 0.63）（p.4）。
- **自評的政治參與、投票率**：沒有差異（p.4）。
- **例外**：
  - 平台上的政治互動**下降**：Facebook −0.117 SD、Instagram −0.090 SD（p.4）。作者認為主要是因為整體互動下降（p.5）。
  - Facebook 時間序組點擊黨派新聞的次數增加（+0.107 SD）（p.5）。
- **次要假設**（信任媒體、對選舉正當性的看法、支持政治暴力等）：幾乎都沒有差異（p.5）。
- 作者結論：可以**排除連中等程度的效果**。這降低了「動態演算法直接造成個人極化」的預期（p.6）。

## 限制（作者自述，p.5–6）

- **時間**：3 個月可能不夠長，雖然已經比多數同類研究長（p.5）。
- **情境**：在高度極化的美國大選期間進行，結果可能不適用於其他國家或其他時期（p.5–6）。
- **「一般均衡」效果測不到**（p.6）：
  - 演算法可能改變創作者、媒體、競選團隊生產什麼內容，這些又會回饋到演算法本身。
  - 實驗只改變個人的動態，看不到這種整體效應。
  - 時間序組看到的貼文，有一部分是由仍在使用演算法的其他使用者分享的。
- **只比較了一種替代方案**（時間序），換成其他排序方式結果可能不同（p.5）。
- **受試者比一般使用者更活躍**（p.3）。

## 勘誤（p.8–10）

- **2024-12**：Instagram 的「不可信來源」變數有處理錯誤。作者估計影響有限，**Facebook 的結果不受影響**（p.8）。
- **2026-03**：Instagram 的「輪播貼文」計算方式不一致，不文明和歧視字眼的比例可能被**低估**。作者認為實驗效果的估計不受影響，Facebook 和問卷資料也不受影響（p.9–10）。

## 與其他來源的關係

- **對照** [[sources/milli-2025]]：
  - Milli 發現 Twitter 的互動導向演算法會放大憤怒和敵視對立陣營的內容，讓讀者短期內對對立陣營感覺更差。
  - Milli 也直接引用本研究，指出兩者的差異在於本研究測的是較長期的整體態度，而且沒有涵蓋一般均衡效果（[[sources/milli-2025]], p.9）。
  - 見 [[syntheses/do-algorithms-polarize]]。
- **呼應** Milli 的發現：Facebook 演算法動態的不文明內容比時間序多（3.2% vs. 1.8%），方向一致（p.4）。
- **但也有反方向的證據**：演算法動態的**不可信來源比較少**（2.6% vs. 4.4%）。作者推測可能和平台降低低品質來源排名的措施有關（p.5）。這讓「改回時間序就比較好」的主張變得複雜。
- **對照** [[sources/hstu]] 的 Impact Statement：HSTU 宣稱更好的推薦可能減少假新聞（p.10）。本研究顯示，2020 年 Facebook 的演算法確實比時間序少了不可信來源，但這不等於證明 HSTU 的主張。
- **平台合作模式**：見 [[syntheses/platform-transparency]] 和 [[concepts/algorithmic-audit]]。
